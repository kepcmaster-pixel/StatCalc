#  StatCalc

A clean, responsive, and interactive statistical calculator built with **HTML, CSS, and JavaScript**. StatCalc allows users to input a list of numbers and instantly calculate descriptive statistics while visualizing the data using interactive charts powered by **Chart.js**.

---

##  Features

-  Accepts numbers separated by:
  - Commas (,)
  - Spaces
  - New lines

-  Calculates:
  - Count
  - Sum
  - Mean
  - Median
  - Mode
  - Minimum
  - Maximum
  - Range
  - Population Variance
  - Sample Variance
  - Population Standard Deviation
  - Sample Standard Deviation

-  Interactive Charts
  - Bar Chart of entered values
  - Histogram showing data distribution

-  Input validation with user-friendly error messages

-  Fully responsive interface for desktop and mobile devices

-  Modern glassmorphism-inspired UI

---

##  Preview

StatCalc provides an intuitive interface where users can:

1. Enter numerical data.
2. Click **Calculate**.
3. View descriptive statistics instantly.
4. Visualize the dataset using charts.
5. Clear the input with one click.
